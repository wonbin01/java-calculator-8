# 문자열 덧셈 계산기

해당 프로젝트는 문자열을 입력받아 그 안에 포함된 숫자를 추출하고, 덧셈 결과를 반환하는 계산기 구현 프로젝트이다.

## 목표(Goals)

- 주요 목표 :
    - 문자열 파싱 및 유효성 검사 로직 구현
    - 예외 처리를 통한 안정적인 프로그램 동작 보장

## 프로그램 흐름 ( 기능 목록 )

1. 입력 받기
    1. 사용자가 문자열을 입력한다( 예 :`“1,2”` 또는 `“//;\n1;2;3”`)
2. 파싱
    1. 기본 구분자 : `,` 와 `:`
3. 검증
    1. 숫자 외의 문자가 포함되어 있는지 검사한다
        1. `“//[delimeter]\n…”` 와 같은 형식인지 확인한다. 올바르지 못한 형식인 경우 IllegalArgumentException 발생
    2. 음수나 0이 포함되어 있는지 검사한다 → IllgalArgumentException 발생
4. 계산
    1. 모든 숫자를 더한 합계를 반환하고 프로그램이 종료된다.

## 세부 요구사항 요약

| 기능        | 설명                                                                                                                                   |
|-----------|--------------------------------------------------------------------------------------------------------------------------------------|
| **입력 처리** | 콘솔 입력 또는 테스트 코드에서 문자열 인자로 입력받는다.                                                                                                     |
| **구분자**   | 기본 구분자: `,`, `:` <br> 커스텀 구분자: `"//[delimiter]\n"` 형태로 지정 가능                                                                         |
| **예외 처리** | - 음수 입력 시 `IllegalArgumentException` 발생 <br> - 0 포함 시 `IllegalArgumentException` 발생 <br> - 잘못된 형식 입력 시 `IllegalArgumentException` 발생 |
| **출력**    | 입력된 숫자의 합을 반환 (입력의 현실적인 범위를 고려해`long` 자료형 사용, <br/>약 900경의 값 처리 가능)                                                                  |

## 기타 예외 처리

- 사용자로부터 입력받아 계산한 결과가 21억을 넘는 경우도 발생할 수 있으므로, 이를 고려헤 계산결과를 최대 900경까지 처리할 수 있도록 long자료형을 사용한다.
  이를 초과하는 경우 IllegalArgumentException 예외 처리를 한다


- 문제 기능 요구 사항을 확인했을 때 ([테크코스](https://apply.techcourse.co.kr/assignment/18/mission/65)), 문자열 “//”와 “\n” 사이에 위치하는 “문자” 라고
  제시했기 때문에, `“//”`와 `“\n”` 사이에 2글자 이상 구분자가 들어가면 IllegalArgumentException로 예외 처리를 한다.


- 입력이 비어있는 경우 `(“”)` 는 0을 반환


- 공백 포함 시 `“1, 2”` 는 공백 제거 후 처리
    - "`1 2,3`" 같은 경우 -> `12,3` 으로 처리한다.(구분자로 공백이 주어지지 않았으므로)


- 반면, 커스텀 문자를 지정하는 경우에는 처음 입력으로 빈칸이 주어지면 IllegalArgumentException을 발생시킨다
    - `" //[delimiter]\n 1,2,3"` 과 같이 주어지는 경우에는 주어진 형식을 지키지 않은 경우이기 떄문에 예외를 발생시킨다.
    - `"//[delimiter]\n 1 2,3` 과 같이 주어지는 경우에는 주어진 형식을 지킨 것으로 보고, `12+3=15`를 반환한다.

## 입력 / 출력 예시

| 입력              | 출력    | 설명         |
|-----------------|-------|------------|
| `“1,2,3”`       | 6     | 기본 구분자 사용  |
| `“1,2,:3”`      | 6     | 기본 구분자 사용  |
| `“//;\n1;2;3”`  | 6     | 커스텀 구분자 사용 |
| `“//;\n1;-2;3”` | 예외 발생 | 음수 포함      |
| `“//;\n1;0;3”`  | 예외 발생 | 0 포함       |
| `"//;;\n1;2;3`” | 예외 발생 | 구분자 2글자 이상 |
| `"//a\n1a2b3”`  | 예외 발생 | 숫자 외 문자 포함 |
